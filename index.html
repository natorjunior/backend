Sessão Inicial

Formato das APIs

Subsessão I.1

Recursos e URIs

  • Um recurso de API é identificado por uma URI (endereço do recurso).
  • A URI parece um endereço web, mas descreve um dado ou ação da API.
  • Formato base: esquema + host + caminho + (query opcional).
protocolo:// host:porta/ caminho/do/recurso? query=params
Subsessão I.2

Exemplo de Formato

https:// api.exemplo.com:443/ v1/alunos/310? ativo=true
scheme
https (protocolo)
host:porta
api.exemplo.com:443 (servidor)
path
/v1/alunos/310 (recurso)
query
?ativo=true (filtros/opções)

Sessão 2

Métodos HTTP

Subsessão 2.1

Métodos HTTP: Quando Usar

  • GET: buscar recurso(s), sem alterar dados.
  • POST: criar novo recurso.
  • PUT: substituir um recurso completo.
  • PATCH: atualizar parte do recurso.
  • DELETE: remover recurso.
Regra de ouro: o verbo HTTP precisa combinar com a intenção da rota.
Evite: POST /deletarTarefa.
Prefira: DELETE /tarefas/:id.

Sessão 3

Corpo da Requisição e Parâmetros

Subsessão 3.1

Três Fontes de Dados na Requisição

req.params
Parâmetros de rota
Ex.: /tarefas/:id
req.query
Parâmetros de consulta
Ex.: ?status=aberta
req.body
Corpo da requisição
Ex.: JSON no POST/PUT/PATCH
Regra prática: identificar recurso -> params, filtrar -> query, enviar dados -> body.
Subsessão 3.2

Exemplos Gradativos


// 1) params
app.get('/tarefas/:id', (req, res) => {
  const id = Number(req.params.id);
});
          

// 2) query
app.get('/tarefas', (req, res) => {
  const status = req.query.status; // /tarefas?status=aberta
});
          

// 3) body
app.post('/tarefas', (req, res) => {
  const { titulo } = req.body;
});

Subsessão 3.4 - Atividade 2

Atividade: POST com body + validação


app.post('/tarefas', (req, res) => {
  const { titulo, status } = req.body;

  if (!titulo) {
    return res.status(400).json({ erro: 'Campo título obrigatório' });
  }

  const nova = { id: Date.now(), titulo, status: status || 'aberta' };
  tarefas.push(nova);
  return res.status(201).json(nova);
});
          

Postman (VSCode) - Body JSON:

  "status": "aberta"
}
Resultado esperado: body válido -> 201, body sem título -> 400.
